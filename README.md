# 🇬🇧 English

## 📌 About

**Telegram Force Join Bot** is a Telegram bot designed to restrict access to bot features until the user joins the required channels or groups.

When a user starts the bot, their membership status is checked. If they have not joined the required channels or groups, the bot displays membership links and provides a button to verify their membership again.

After successful verification, the bot can unlock the main menu and display a welcome message.

## ✨ Features

* 🔍 Check user membership in channels or groups
* 📢 Support multiple required channels/groups
* 🔗 Send membership links with inline buttons
* ✅ **"I Joined"** button for re-verification
* 🔒 Restrict bot features until membership is confirmed
* 👋 Display a welcome message after verification
* 🏠 Activate the main menu after successful membership verification
* ⚡ Fast membership verification flow

## ⚙️ How It Works

1. The user sends `/start`.
2. The bot checks the user's membership status.
3. If the user has not joined the required channels/groups, membership links are displayed.
4. The user joins the required channels/groups.
5. The user presses **"✅ I Joined"**.
6. The bot checks the membership status again.
7. If verification succeeds, access to the bot's features is enabled.
8. The welcome message and main menu are displayed.

## 🎯 Use Cases

This bot can be useful for:

* 📢 Channel promotion
* 👥 Growing communities
* 🔒 Restricting bot features to members
* 🤖 Telegram bot management
* 📣 Community-based bot services

## ⚠️ Important Note

The bot should be configured and used responsibly. Users should be clearly informed which channels or groups are required for access.

# 🇮🇷 فارسی

## 📌 درباره پروژه

**Telegram Force Join Bot** یک ربات تلگرامی برای محدود کردن دسترسی کاربران به امکانات ربات تا زمان عضویت در کانال‌ها یا گروه‌های مشخص است.

هنگام اجرای `/start`، وضعیت عضویت کاربر بررسی می‌شود. اگر کاربر عضو کانال‌ها یا گروه‌های موردنظر نباشد، لینک‌های عضویت به همراه دکمه‌های مربوطه برای او نمایش داده می‌شوند.

پس از عضویت، کاربر می‌تواند با زدن دکمه **«✅ عضو شدم»** وضعیت خود را مجدداً بررسی کند. در صورت تأیید عضویت، امکانات ربات و منوی اصلی فعال می‌شوند.

## ✨ قابلیت‌ها

* 🔍 بررسی عضویت کاربر در کانال یا گروه
* 📢 پشتیبانی از چند کانال یا گروه
* 🔗 ارسال لینک عضویت با دکمه
* ✅ دکمه **«عضو شدم»** برای بررسی مجدد
* 🔒 جلوگیری از استفاده از امکانات ربات تا زمان تأیید عضویت
* 👋 نمایش پیام خوش‌آمد پس از تأیید
* 🏠 فعال‌سازی منوی اصلی پس از عضویت
* ⚡ بررسی سریع وضعیت عضویت

## ⚙️ نحوه عملکرد

1. کاربر دستور `/start` را ارسال می‌کند.
2. ربات وضعیت عضویت کاربر را بررسی می‌کند.
3. در صورت عضو نبودن، لینک کانال‌ها یا گروه‌های موردنیاز نمایش داده می‌شود.
4. کاربر در کانال‌ها یا گروه‌های مشخص‌شده عضو می‌شود.
5. کاربر دکمه **«✅ عضو شدم»** را انتخاب می‌کند.
6. ربات وضعیت عضویت را مجدداً بررسی می‌کند.
7. در صورت تأیید، دسترسی کاربر به امکانات ربات فعال می‌شود.
8. پیام خوش‌آمد و منوی اصلی نمایش داده می‌شود.
